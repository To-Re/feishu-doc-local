# 浏览器版：静态托管，本地文件

浏览器版与本地服务版使用同一套编辑器、DocxXML 解析及评论协议。它通过桌面 Chrome 的 File System Access API 访问用户明确选择的目录，不启动 Node 服务、不调用 CLI，也不发送文章给静态托管方。

## 使用

1. 用桌面 Chrome 打开通过 HTTPS 或 localhost 提供的页面。
2. 点击选择目录，并在浏览器原生窗口中授予读写权限。建议先用包含公开样例的测试目录。
3. 在目录根下选择 XML，或新建文档。图片与附件的相对目录保持原样。
4. 编辑正文、切换源码或选中文字评论。只有显示已保存后，磁盘中的 XML 与旁置 JSON 才是本次保存完成的版本。
5. 告诉 AI 读取这两份文件。外部改动与尚未保存的网页输入冲突时，先处理冲突，不强行覆盖。

本版刷新后重新选择目录；不保存目录授权句柄或正文到 IndexedDB，不使用共享的用户根目录项目配置。显示的路径为授权目录名称和相对路径，不是系统绝对路径。

## 保留与限制

保留编辑、只读、源码、选文评论、回复与处理状态、文章目录、相邻 JSON、常见格式与本地资源渲染。左侧“文件”用于选择稿件，“目录”用于按标题跳转。目录选择取消属于正常操作。无效 XML 不写入文件；未保存输入和未提交评论需要先处理再切换文档。

本版不支持飞书正文或评论同步、本机 CLI、按绝对路径打开任意文件、跨浏览器共享项目配置。当前只列授权目录根下的 XML，不扫描整块磁盘。不支持目录读写 API 的浏览器会显示说明；本版没有以下载替代自动保存的隐式降级。

网站会下载自己的静态程序及字体，但文档、评论和本地资源不经网络 API 上传。点击正文中的外部链接仍会访问对应网站。静态托管方的访问日志属于托管服务本身，不在本项目的本地文件存储范围内。

## 保存与恢复

保存前读取 XML 与 JSON 的当前字节摘要，与本次编辑的基线比较。正文变化时先在旁置 JSON 记录 `pendingWrite` 恢复信息，再写正文，最后完成 JSON；中断后重新打开可检查并恢复已准备的写入。发现新的外部修改则保留文件并提示冲突。

同源网页写入使用 Web Locks 协调；浏览器目录 API 不提供覆盖任意外部进程的文件系统锁，也不提供 XML/JSON 跨文件原子提交。因此不能承诺同时运行的外部编辑器永远无竞争。等待保存完成、保留备份，并在冲突时核对两份内容。不要为了消除提示手动删除未知状态的恢复记录。

## 与 Obsidian 插件的区别

Obsidian 基础插件复用本地编辑与评论界面，通过 vault API 保存，另有插件本地草稿恢复；不用浏览器目录授权，也无需 Node 服务。静态浏览器版刷新后需要重新选择目录，不具备插件 `data.json` 的宿主恢复存储。

飞书同步属于独立的 Obsidian 可选扩展，需要基础插件与用户已安装、已登录的官方 CLI。扩展在桌面应用内直接调用 CLI，仍不需要网页服务。静态浏览器版不会因为安装了该扩展而获得 CLI 或飞书权限。见 [基础插件](../obsidian-plugin/README.md) 和 [同步扩展](../obsidian-sync-plugin/README.md)。

已有共享编辑器与文件协议的自动化测试，以及浏览器目录折叠和点击定位记录。Obsidian 另有模拟宿主检查和实际窗口中的部分编辑、评论与云端读取预览；完整插件云端往返仍未验收。详见 [2026-09-13 验证记录](validation-2026-09-13-plugins.md)。

## 构建与静态托管

```sh
npm ci
npm run build:browser
npm run preview:browser
```

输出目录为 `dist/browser/`，可上传到任意支持 HTTPS 的静态托管服务。Cloudflare Pages 的构建命令可设置为 `npm run build:browser`、输出目录为 `dist/browser`，构建环境使用 Node 22.13+。不需要 Worker、数据库、服务端凭证或云端文档 API。

应发布整个输出目录，保留字体、`LICENSE`、`THIRD_PARTY_NOTICES.md` 和 `licenses/`。不要上传整个源码工作目录、`.local`、用户 XML/JSON 或下载缓存。实际托管与访问验证需另行执行；本地构建通过不等于已经上线。

浏览器 API 依据：[Chrome File System Access](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access)。
