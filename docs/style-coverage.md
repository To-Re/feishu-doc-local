# 格式支持与限制

本项目解析官方 CLI 的 DocxXML，在本地渲染和编辑。飞书网页版用于视觉与交互对照；本地并未嵌入飞书编辑器，支持程度也不等于云端无损往返。

## 本地能力

| 格式 | 可以做什么 | 限制 |
| --- | --- | --- |
| 标题、正文、列表、引用 | 标题 `h1–h9`、自动编号、对齐、富文本、待办、高亮块；支持正文编辑与评论 | 编号、对齐、颜色等部分属性尚无专用工具栏，可通过源码修改 |
| 代码 | 代码编辑、语法高亮、行号和评论 | 未知语言显示普通代码，无语言和标题设置入口 |
| 表格 | 单元格编辑、富文本、合并单元格、列宽及背景呈现 | 没有合并或列宽调整工具栏；不是飞书电子表格 |
| 公式 | KaTeX 渲染；选中已有公式，在侧栏修改源码并应用 | 没有新建公式入口；无法呈现时保留表达式与错误提示 |
| 分栏 | 按比例展示，栏内正文可编辑 | 没有比例调整工具栏 |
| 图片与附件 | 显示本地图片、已缓存资源和附件卡片；可整体评论，资源树可只读查看支持的文件 | 不编辑附件内容，不自动加载未缓存的远程资源 |
| Mermaid、SVG 白板 | 内联图源可预览、修改、保存和撤销；有节点结构时可选择组件评论 | 布局可能与飞书不同，没有原生拖拽绘图工具 |
| 其他白板 | 空画布、已下载的栅格或安全 SVG 预览 | PlantUML 不在本地编译；仅有 token 且无缓存时不能显示真实画面 |
| 电子表格与云动态块 | 保留原 XML，未支持内容显示保护占位 | 无电子表格内部编辑、完整云卡片或跨文档动态引用编辑器 |

未知 XML 保留原文，保护占位不代表内部内容已经支持。评论引用不可靠时标记待确认，不按相同文字猜位置。图片、公式、附件可以整体评论；本地白板组件意见同步到飞书时按整图定位。

可打开[综合格式样稿](../examples/compatibility.xml)、[本地资源样稿](../examples/local-resources.xml)和[白板样稿](../examples/whiteboards.xml)体验。含示意 token 的样例不应用作真实资源直接发布。

## 飞书往返的已知差异

| 项目 | 已记录的差异及处理 |
| --- | --- |
| 行内附件后的正文 | 官方 CLI **v1.0.95** 的 macOS 实测中仍丢失附件后文；命令成功不等于内容完整。先用副本验收，旧稿快照必须保留。 |
| 块 ID 与结构 | 首次发布由飞书分配真实 ID，部分结构更新可能重建块；回读更新本地后，无法可靠对应的评论引用需重新确认。 |
| 分栏、图标和链接预览 | 已观察到三栏比例变成等宽、警告图标被替换、链接预览属性变化等情况。 |
| 颜色、空段落与媒体属性 | 颜色值、空白、图片名称、caption 等可能规范化；原 XML 与云回读不保证字节相同。 |
| 白板 | 静态预览、Mermaid 排版和边线标签可能不同；公开评论接口未覆盖飞书内部节点锚点的完整往返。 |

以上是指定版本的实测记录，不表示所有新版 CLI 都有相同问题，也没有把尚未复测的版本当作已修复。[官方 CLI 实测](archive/official-cli-mac-2026-09-13.md)与[完整样式对照](archive/style-coverage-2026-09-13.md)保留原始验收范围。

同步采用“预览 → 确认执行”；推送成功后回读更新本地，覆盖前的 XML 和评论另存快照。结果不确定、下载失败或期间发生新修改时停止覆盖，详见[同步与恢复](projects-and-sync.md)。

## 验证范围

目前以 macOS 为验证平台。浏览器与官方 CLI 已完成指定样稿的正文、资源和评论往返；Obsidian 已完成部分本地编辑、评论、导入及拉取实测，插件内真实发布、评论云同步与完整双向往返仍未完成全部验收。

自动化测试、局部操作、静态预览和协议回执各自证明不同内容，不代表所有样式、插件窗口或平台都已通过。阶段证据见[历史验收记录](archive/README.md)。
