# 本地阅稿体验验收 · 2026-09-12

本轮分别进行编辑评论、资源导航的真实浏览器验收，以及公式和白板草稿的数据保护审查，再独立复核窄窗口与修复结果。所有操作使用隔离副本，原样稿 XML 与评论 JSON 的 SHA-256 校验保持不变。

## 问题与改动

| 复现的问题 | 修复后的行为 |
| --- | --- |
| 从正文中段打开附件，再返回会回到开头 | 按文档、文件分别保存阅读位置；文本预览同时保留横向和纵向滚动 |
| 附件预览中点评论引用，正文仍隐藏；只读模式有时不滚到引用 | 先切回正文，编辑器和浏览器选区同步定位；只读引用也滚到可见区域 |
| 外部修改附件后，预览无法刷新 | 资源页提供刷新；失败保留旧内容并明确标识，恢复文件后可重试 |
| 窄窗口的评论入口在整篇长文后，编辑模式按钮滚出视口 | 顶部工具栏固定；选文评论入口始终可达；评论按需展开为侧面板 |
| 关闭面板后，再点同一公式不能打开编辑器 | 点击已选中的公式或可编辑白板也重新打开面板 |
| 公式、白板未应用的草稿在切选区后丢失 | 按源节点身份保留草稿，移动位置、切选区与切模式均不丢失 |
| 隐藏或清空图源草稿后，离开页面和外部同步不再受保护 | 以实际 dirty 状态保护打开文档、页面离开和自动回读；顶部显示未应用修改 |

原节点被删除或身份重复时，保留可复制的草稿并暂停应用；源内容在草稿期间发生变化时明确提示冲突。应用或还原后才解除对应草稿保护。正文及已发送评论仍通过原有自动保存写入 XML 和相邻 JSON。

## 验证范围

- 真实浏览器：编辑与只读选文评论、回复、解决、重新查看、刷新后落盘一致；资源树与路径复制；正文/JSON/TXT/CSV/图片切换；TXT 外部修改、暂时缺失、恢复与刷新；评论引用定位；资源页直接返回正文。
- 阅读位置实测：正文往返前后 `scrollY` 均为 `3562.5`；TXT 往返及刷新前后 `scrollTop=1000`、`scrollLeft=260`。
- 补充检查 768 × 942、375 × 812 窗口：工具栏、公式面板和评论输入可见，页面没有横向溢出；使用按需展开的评论面板。
- 集成测试使用真实 App、Reader、ProseMirror，模拟本地文件 API；覆盖草稿隔离、空草稿、节点移动/删除/撤销、源冲突，以及隐藏草稿时阻止外部回读。这些结果不冒充浏览器视觉验收。
- `npm run typecheck`、`npm test`（19 个测试文件、174 项）、`npm run build` 均通过。
- 未操作真实系统文件选择器或飞书云端，本轮不扩大此前的云端样式验收结论。
