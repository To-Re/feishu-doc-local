# 工作区布局验收 · 2026-09-12

> 历史验收记录，描述当时版本；当前用法见[使用文档](../README.md)。

初次评审发现飞书目标藏在评论区，顶部多行按钮缺少主次。本次把文档上下文和编辑工具分为两层：第一层保留项目切换、本地路径、飞书链接、同步方向与“预览同步差异”；第二层放编辑模式、格式和评论。新建、打开、共享设置归入“项目操作”。同步结果和创建时提示随页面滚动。

预览资源时，路径栏标注“资源”，另显示正文同步所针对的 XML。同步确认页同时列出完整本地路径和飞书链接。云端目标取自当前有效项目，未发送评论阻止切换时仍保留原目标；仅本地项目不显示旧目标。

## 多人评审与修复

实现与独立评审分别检查操作层级、文档目标、键盘行为和窄屏布局，发现并修复：

- 新建弹窗原先受顶部堆叠层限制，可能被窄屏评论面板遮挡；改为挂到页面根部，保留独立操作锁。
- 鼠标打开评论后立即按 Escape 不能关闭；统一入口焦点，关闭时返回触发按钮。
- 非模态评论面板、项目和格式菜单在 Tab 离开后仍覆盖其他焦点；离焦收起并保留评论草稿。
- 真实浏览器补测发现，点击评论面板内不可聚焦的说明文字也会使面板收起；只在焦点明确移到面板外时关闭，保留内部点击和评论草稿。
- 同步预览只有项目名称，缺少准确写入对象；补齐本地 XML 绝对路径和完整飞书链接。
- 创建时的权限提示会被后续输入清除；在当前页面会话中单独保留可关闭的历史提示，不将它当成当前权限状态。

## 真实浏览器检查

使用独立测试项目索引和新增本地验收稿。桌面直接打开真实服务；窄屏夹具承载同一份编译客户端，连接同一测试服务，在浏览器中设置实际 iframe 视口。夹具及截图留在忽略的 `.local`，应用自身的禁止嵌入策略未修改。

| 场景 | 实际结果 |
| --- | --- |
| 1280 × 720 桌面 | 顶部高度从 225 px 降到 130 px，三栏可见，飞书链接常驻，无横向溢出 |
| 375 × 667 窄屏 | 顶部从 249 px 降到 176 px，格式收进菜单，云端入口与同步预览可见，无横向溢出 |
| 320、561、640、768 px 宽度 | 文档横向宽度等于视口宽度，本地与云端上下文未相交 |
| 375 × 320 短屏 | 评论面板保留可见关闭入口，实际点击后焦点位于关闭按钮，内容区允许独立滚动 |
| 评论 → 项目操作 → 新建 | 点击菜单收起评论，新建表单没有遮挡，项目名称获得焦点，取消可返回 |
| 创建仅本地项目 | 从菜单创建成功；浏览器输入落到新 XML，旁置 JSON 建立；页面没有残留飞书目标或同步入口 |
| 切回云端项目及查看图片 | 恢复对应飞书链接；图片路径标为资源，正文同步对象仍显示正确 XML |
| 从资源预览发起同步预览 | 真实云回读显示两端相同；预览列出正确 XML 与飞书链接，仅提供关闭，不执行云写入 |
| 未发送白板组件评论后切换 | 实际切换被阻止，评论文字、选中项目与飞书链接保留；取消草稿后可切换 |

键盘 Escape、Tab 离焦、草稿保持和焦点返回还通过真实 App/Reader 组件回归验证；这些用例不冒充浏览器键盘实测。jsdom 不提供选区几何，测试补充并在清理时恢复对应接口；不以零几何结果证明实际排版。短屏检查不覆盖真实手机软键盘。
