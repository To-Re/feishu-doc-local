测试覆盖同一次保存锁中的准备与执行、重复点击、迟到输入、云端与本地并发修改、无效回读、资源下载失败、资源变化，以及新建失败后保留云端身份和待定记录。未完整确认的发布不会自动重发。

## 隐私与分发边界

公开源码由 `scripts/prepare-public-source.mjs` 按白名单独立导出，并附相对路径、字节数和 SHA-256 清单；重新建立公开初始提交，只发布 `master` 和版本标签。原开发历史保留在本机，不上传实验分支或私人验收记录。

源码和构建扫描检查私人目录、内部租户与真实文档标识、私钥、常见访问令牌、JWT、运行配置和旁置用户数据。检查范围内未发现需要排除的私人信息。测试中的虚构路径和恶意 URL 输入保留用于安全回归；第三方许可证的作者归因也予以保留。

公开图片已做视觉与元数据核对。飞书空白画板插图及真实文档下载缓存不作为项目素材分发。字体内嵌编码的模式命中已按依赖字体内容核验，不能据此认定为真实凭据。

四个 ZIP 由独立白名单打包，排除 `.git`、`.local`、`.obsidian`、用户 `data.json`、评论文件、同步备份、`node_modules`、构建元数据和 source map。时间及权限使用固定值，不携带本机文件元数据。发布页的 `SHA256SUMS` 对应实际安装包，源码清单对应实际导出的文件。

维护者使用公开 GitHub noreply 身份，Codex 列入贡献说明，并在首版提交保留共同作者标记。归因不改变第三方代码及资源的许可证。
