## 网页与 Obsidian 数据共享的边界

网页与 Obsidian 保存的正文、评论、回复与处理状态采用相同 XML／旁置 JSON 协议，资源路径相对于稿件。共用同一份文件时可互相读取已保存内容；这项协议一致性不等于已完成各实际窗口之间的交叉编辑验收。

项目名称、文稿路径、飞书关联和默认同步方向由 `projects.json` 保存。本地服务版与 Obsidian 同步扩展使用同一索引协议，但只有配置为同一绝对路径才共用项目列表；静态网页与 Obsidian 基础插件不读取这个用户级索引。Obsidian 只能打开当前 vault 内的稿件。未发送评论和无效源码草稿不随项目索引共享：独立网页将其留在页面内存，并在离开时提醒；Obsidian 另有宿主私有恢复记录，不能据此宣称普通网页关闭后也能恢复草稿。

项目索引写入使用跨进程锁和写前回读；云端同步使用相邻的同步锁。普通正文保存有双文件版本校验与恢复记录，但各宿主的局部锁不构成跨应用同时编辑的全局互斥，也不是多人实时协同协议。

## 复查命令

在仓库根目录安装依赖后，执行共享检查：

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run build:browser
```

两个 Obsidian 插件分别检查：

```sh
npm ci --prefix obsidian-plugin
npm run typecheck --prefix obsidian-plugin
npm test --prefix obsidian-plugin
npm run build --prefix obsidian-plugin
npm ci --prefix obsidian-sync-plugin
npm run typecheck --prefix obsidian-sync-plugin
npm test --prefix obsidian-sync-plugin
npm run build --prefix obsidian-sync-plugin
```

构建后核对第三方许可证：

```sh
node scripts/generate-third-party-notices.mjs --check --verify-bundle
```

这些测试使用脱敏数据，不应为了执行检查而提供账号、登录令牌或生产文档。
