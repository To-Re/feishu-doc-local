# 本地附件预览验收

本轮解决两个不同问题：素材未下载时给出准确提示；已下载的文本、视频和音频能够在本地阅读或播放。没有将远程 token 当作本地文件，没有修改云端正文或自动扩大访问权限。

## 变更

- Markdown、文本和代码附件以只读文本展开；卡片按需展开，Preview 直接预览。HTML/SVG 附件不会作为网页执行。
- 本地 MP4/M4V/WebM、MP3/WAV/OGG 使用浏览器原生播放器；正文和资源树共享本地资源，单文件上限 25 MB。
- 服务端保持当前文档会话、同源和路径边界，增加单段 Range 响应供进度跳转；拒绝未引用的影音、链接、特殊文件及容器标识不符的文件。
- 缺失素材与格式不支持分别提示。切文档取消文本读取、停止播放器并释放本地 Blob。
- 补充旁置文件协议：`document.name` 必须等于 XML 文件名，不能用文章标题。

## 验证

- 主程序类型检查、64 个测试文件共 815 项测试通过；无未处理异常。
- Obsidian 基础插件类型检查、88 项测试通过，包括模拟 Vault 的视频与 Markdown 读取；最后的资源清理调整另通过附件相关的 53 项增量测试。
- 本地服务、静态浏览器和 Obsidian 基础插件构建通过。
- 三份真实本地资料通过共享解析、模拟 Vault 读取、DOM 渲染和 XML 字节一致的往返检查；18 份已缓存素材均可读取。
- 另生成不含私人资料的 2 秒 H.264/MP4 样稿；容器与编码经 ffprobe 检查。自动化 HTTP 测试核对全量读取、Range、缺失、伪装及未引用文件处理。
