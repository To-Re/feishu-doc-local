# 同步预览与本地快照恢复验收

> 历史验收记录，描述当时版本；当前用法见[使用文档](../README.md)。

本轮统一网页服务版与 Obsidian 同步扩展的正文操作：顶栏只有“预览同步”，方向和唯一确认动作位于预览顶部；关联设置不再重复正文、评论执行入口。恢复上一快照位于管理/关联设置，采用独立本地恢复预览。

## 自动化与独立评审

- 根目录类型检查及 765 项测试通过；新增真实 HTTP 恢复、跨项目预览重放拒绝、预览后修改阻断，以及界面取消、切方向、过期、卸载后的请求阻断。
- Obsidian 同步扩展类型检查、144 项测试与构建通过，包含 55 项模拟宿主界面测试。测试覆盖单一正文入口、关联页去重、预览不执行、确认执行当前方向、恢复前 lease、窗口关闭与路径变化。
- 恢复核心 30 项真实临时文件测试包含恢复与撤回、备份失败不覆盖、损坏/软链接/资源变更拒绝、未确认云操作阻断、保留已发送评论身份及不重发。可信目录内的“网页快照 → Obsidian 恢复 → 网页撤回”通过。
- 三个 agent 分别实现网页、实现 Obsidian、核查快照安全，并交叉评审。评审发现的“页面卸载后等待保存仍继续提交”和“恢复期间切换配置导致备份位置不一致”问题已修复并加入回归。
- 快照随当前项目配置保存，默认及自定义配置位置、原实例归档兼容和恢复期间禁止切换配置均通过真实 HTTP 测试。全量复测发现 6 项旧断言仍指向原实例目录；更新为当前配置目录后，关联及配置两组 36 项测试全部通过，其余 729 项此前全量通过。
- 网页服务版、静态浏览器版与同步插件构建通过；分发许可证核对通过。

## 实际浏览器点击

使用独立 loopback 服务、公开生成的测试文章、真实本地 XML/JSON 与本地模拟云端传输。没有使用真实飞书文档或凭证。

1. 顶栏仅一个正文同步入口；预览分别显示拉取/推送，红绿差异方向相反且确认按钮匹配。检查了实际截图与 DOM。
2. 预览、切换方向、关闭均未改变本地正文；模拟云端只发生读取，没有写入。
3. 从项目管理打开恢复预览，确认后页面与磁盘正文都回到旧稿，恢复前的正文和评论备份可读取。
4. 再次预览并确认拉取，页面与真实磁盘采用模拟云端正文；独立核对旧 XML 与评论快照存在且内容正确。
5. 再次从管理页预览并恢复到拉取前版本，正文刷新正确，浏览器没有记录控制台错误。

## 验证边界

本轮真实 Obsidian 窗口读取被自动审批阻断，因为可能包含测试目录外的私人文章；未完成真实 Obsidian GUI 复验。模拟宿主与真实浏览器验收不能替代该项，也不能当作真实飞书双向往返通过。

快照记录资源引用和哈希，资源二进制保留在原位，并非复制所有图片和附件。资源被删除或改变时恢复会阻止覆盖；早期快照无历史资源哈希，会提示人工核对。跨端恢复要求两端使用对应的可信项目配置目录，不会根据任意操作文本扫描用户磁盘。
