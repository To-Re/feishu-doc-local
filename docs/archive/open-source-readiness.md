## 结果

检查了 21 个可达提交、308 个文件内容对象和 121 个目录对象，以及当时的 379 个已跟踪或未被忽略的新增候选文件。另检查了网页与 Obsidian 插件分发目录中的 167 个文件；第三方许可证单独保留来源归因。

- 未检出真实私人绝对路径、内部服务域名、真实云文档或用户标识、私钥及常见访问令牌模式。疑似绝对路径均为界面示例或测试占位；疑似邮箱的历史匹配来自刻意构造的 URL 拒绝测试，不是登录账号。
- **一个历史提交的作者及提交者元数据未采用公开 GitHub noreply 邮箱。** 原值只保存在被忽略的私有报告中，不在此公开。其余提交使用公开 GitHub noreply 邮箱。没有直接修改或改写这些提交。
- 旧文档中存在个人工作区名称、替代 CLI 的本机使用约定和执行过程记录。当前贡献规范及公开文档已改为可独立使用的项目说明；历史兼容性验收继续区分官方发行版、修复候选与其他兼容实现，不把替代实现的结果归给官方版本。
- 已检查的 PNG 仅有图像必需的数据块，没有 EXIF 或文字元数据；SVG 和示例图源未包含个人创作者元数据。截图中的平台插图来自私有文档缓存，未作为项目素材分发，详见 [资源来源与分发边界](../assets-and-attribution.md)。

这些结果不表示旧 Git 历史已经清洗，也不使用户文档或下载资源获得开源授权。

## 导出范围

公开交付采用整理后的文件快照，重新建立使用公开贡献身份的仓库，不直接推送当前开发仓库历史。原仓库与私有验收记录继续留在本机，便于回查兼容性结果。

导出应包含源码、公开样例、构建与测试配置、贡献文档、项目许可证和完整第三方通知。排除 `.git/`、运行数据、个人配置、凭据、真实文档与旁置反馈、下载缓存、原始回执及私有截图。不要通过复制整个工作目录再删除少数已知文件的方式生成公开包；用明确的发布文件范围建立候选目录，再核对实际内容。

公开示例只使用占位文档身份与明确可分发的素材。测试中的非法 URL、虚构身份和占位路径是安全回归输入，需要保留其测试作用；它们不应被误识别为真实账号并删除。第三方作者姓名、公开邮箱、版权与许可证同样不因隐私清理而删掉。

## 检查方法与边界

历史检查读取所有可达提交及文件内容，覆盖源代码、样例、测试、注释、提交元数据和文本型配置；当前文件检查也包含尚未提交但准备公开的新文件。匹配项只按位置与类别进入私有报告，未将原始身份复制到公开结论。

检查包括私人工作区指向、用户目录、内部域名、长云端标识、邮箱、常见密钥及令牌格式、凭据字面量，以及图片元数据。对命中项人工区分占位测试、第三方归因和应排除的信息。未读取凭据存储，也没有为检查连接云端。

Obsidian 插件的实际入包审计识别出 110 个依赖包版本，均有 `licenses/dependencies.json` 对应记录。插件样式中的字体全部嵌入，无远程字体 URL；KaTeX 字体 OFL 和图标等依赖的许可与项目 MIT 分开保留。完整分发依据见 [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md)。

正则和文件审查不能穷尽所有隐私或秘密形式。本记录对应检查当时的文件；发布前还需对最终导出目录、压缩包成员、图片和重新构建产物复查，确认没有混入后来新增的配置或用户数据。这里不把本地检查写成已公开发布或所有环境均已验收。

## 当时的实现验证

2026-09-13 的最终本地回归通过 54 个测试文件、661 项测试；另有 Obsidian 插件 7 项测试通过。主项目和插件类型检查、本地服务构建、浏览器静态构建、插件构建均通过。实际构建路径核对覆盖 118 个依赖包路径，所需许可证和字体归因均在清单中。

新增浏览器文件层的 27 项测试覆盖保存、外部修改、恢复日志、权限和资源路径；14 项界面测试覆盖编辑、评论、源码、切文件与冲突恢复。这些测试使用目录 API 能力替身，不能替代原生目录选择器及实际浏览器磁盘写入的端到端验收。当前后两项、以及 Obsidian 桌面应用内启用和渲染验收仍待完成；不将它们记为通过。

公开源码导出工具见 `scripts/prepare-public-source.mjs`：仅复制允许的源码路径及已扫描字节，拒绝软链接、运行目录、下载缓存、旁置评论和常见凭据文件；生成相对路径与 SHA-256 清单。正常导出、缓存拒绝、私人路径拒绝、软链接拒绝和已有目标不覆盖五项临时目录检查通过。导出不继承开发仓库历史，也不执行远程发布。
