# 发布回读与界面验收

> 历史验收记录，描述当时版本；当前用法见[使用文档](../README.md)。

本页为 2026-09-13 的历史实现与验收记录。当时采用回读需要单独确认；当前入口已改为明确推送后自动更新本地并存档旧稿，冲突与不确定结果仍受保护。新交互见 [项目与同步指南](../projects-and-sync.md)，本页步骤不作为新交互的实测证明。

本轮使用已发布的全样式测试稿做只读比对。正文及资源的采用流程只操作独立副本，源 XML 和相邻反馈的哈希保持不变，没有云写入。私有完整回读、截图和验收副本保存在 `.local/style-compare-20260913/`。

## 发布与采用回读分开

创建或发布成功后保留工作稿，不因云 ID、格式规范化或内容变化自动覆盖。同步快照中同时保存原稿 `local.xml`、原反馈 `local.review.json`、云稿 `cloud.xml` 和完整回执；相邻反馈保留双方基线，操作记录写明备份目录。

人或 AI 核对差异后，可明确确认采用飞书回读。这时才下载资源并更新本地，写前重查版本、素材和本地修改；取消、超时或资源失败保留原稿。没有可靠对应关系的评论保留文本和回复，将引用标为待确认。

回归用例包含云回读删除整段正文的情形：创建和发布均保留本地原段落、评论和素材；二次预览不改文件，只有再次确认才采用。发布不依赖资源下载，真实发布的回读或备份失败仍保留 pending。

## 本地文件与真实云回读

独立验收副本通过实际浏览器执行“预览 → 确认采用”，完成 2 次完整读取和 18 次资源下载，均使用真实 CLI 的只读命令。包装器拒绝其他命令并留下审计记录。确认前副本与原 XML/JSON 逐字节相同；确认后副本正文、反馈快照和双方基线一致，18 项资源映射落盘，无 pending，覆盖前原稿可恢复。

副本还通过“项目管理 → 修改 → 保存”切换配置目录。目标索引保留完整项目登记，原索引和文章仍在原位置；重新加载后显示已保存的新目录。新安装默认用户目录、旧实例保留路径、重复绑定和并发冲突由临时目录与实际 HTTP 回归覆盖。

## 样式核对

| 范围 | 本次结论 |
| --- | --- |
| Mermaid 简单流程图、时序图、条件分支图 | 飞书最新完整回读与发布快照相同，三份图源 trim 后完整保留。本地改为无阴影、较细边线及紧凑节点；按自然宽度居中，小图不再强制铺满正文。显式颜色与组件选择 ID 保留。已实际查看本地与 Chrome 飞书图形，不声明布局逐像素相同。 |
| 代码、表格与公式 | 两段代码恢复 `br` 换行后与输入相同；两张合并表的跨度和有效列宽一致；四条 LaTeX 相同。 |
| 颜色与图片 | 命名颜色对应当前按用途划分的 RGB 色板；图片原尺寸乘缩放后均为 360×90，和本地指定尺寸一致。 |
| 附件 | 十处 source 的文件名、大小和前中后正文保留；副本能下载并记录资源。此次未逐项对全部附件重做哈希相等断言。 |
| 三栏比例 | 25%/50%/25% 经 XML 服务变为等宽，仍是导入保真缺口；不能靠覆盖本地成等宽来掩盖。 |
| 警告图标与预览链接 | 警告图标变为灯泡，预览链接类型省略；原图标语义和预览属性未据此通过。 |
| 原生白板图片 | 下载可用，但 API 返回的大画布带大量空白，部分 SVG/PlantUML 缓存图在本地偏小。内联 Mermaid 的改进没有解决这一独立缺口。 |
| 电子表格及动态块 | 本地仍有保护占位，原 XML 保留不等于原生编辑能力完整。 |

标题也需单独核对：创建弹窗的云标题默认来自项目名称，原稿标题和对齐可能不同。该差异不能直接归因为 CLI 删除了正文。

## 界面

顶部“新建项目”和“切换文档”是一级入口，悬停及键盘焦点解释用途。“项目管理”仅显示实际项目配置路径和“修改”，编辑后保存或取消；旧共享开关、候选目录和管理文件的多套展示已移除。项目名称右侧常驻“切换项目”与下箭头，不再显示额外图标或悬浮提示。本地路径与飞书链接的复制按钮紧邻文本，复制完整值。

最终类型检查、构建和全量 51 个测试文件、614 项回归通过。实际浏览器在 768 与 1280 像素宽度下核对布局；768 下本地与飞书复制按钮距离文字均为 5 像素，无横向溢出，两种复制均有原位成功反馈。已修正旧样式覆盖新样式、导致路径输入框宽度为零的问题。375 像素只有交互与弹层计算回归，未记为实际布局验收。自动测试中的模拟云写入不冒充本轮真实云发布。
