# 文件栏与项目选择交互验收 · 2026-09-12

下文前半部分保留初次实现的记录。后续评审发现展开入口会换位置，当前行为按末节“固定入口修正”执行。

初次评审发现文件栏有两个重复的收起按钮，项目选择框还会向上弹出。本轮把文件栏交互收敛为：展开时只保留栏内收起按钮；收起后才在顶部路径旁显示小恢复按钮。收起不卸载文件栏，重新展开保留目录状态和滚动位置；焦点在收起后转到恢复按钮，展开后回到文件栏。

项目选择由网页自己的列表承载，固定出现在标题下方。列表显示名称、本地路径和当前项目标记，长名称换行，列表超高时内部滚动。方向键只移动候选，Enter 或空格确认；Escape、Tab 和外部点击关闭。项目标题和勾选项始终跟随实际接受的项目，不因点击候选提前改变。正文同步方向仍使用原有选择控件。

本轮还删除了正文上方的装饰标题、正文底部的重复文件位置、侧栏重复目录路径和评论区的多段引导。完整路径保留在顶部，可直接复制；XML、评论 JSON 和引用资源仍可从文件栏打开。资源预览时工具栏显示“资源 · 只读”，回到正文后恢复之前的编辑或只读模式。保存、冲突、同步范围与结果提示继续保留。

设计参考 [NN/g 的界面精简原则](https://www.nngroup.com/articles/aesthetic-minimalist-design/) 和 [W3C 的选择式组合框示例](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/examples/combobox-select-only/)。本项目选择操作可能被草稿状态阻止，因此关闭和确认分开处理，Tab 关闭不切换；不宣称完整复现示例或通过所有辅助技术认证。

## 固定入口修正

后续评审确定展开和收起应留在同一位置。将顶部左上角原装饰图标替换为常驻的文件栏开关，展开与收起使用同一 DOM 按钮，固定 32 × 32 px，只更新图标、提示及 `aria-expanded`。文件栏和路径栏中的旧按钮均移除。焦点始终留在开关，重新展开文件栏不再把焦点移到文件列表。

滚动位置通过文件栏打开时的滚动事件记录，重新展开只恢复滚动；保持组件挂载和目录状态。回归验证同一按钮、唯一入口、焦点、资源预览和滚动保持，独立复核通过。最终类型检查、构建和完整测试通过：41 个文件、466 项用例。

在主页面 768 × 942 的真实浏览器中，连续收起、展开、再收起的按钮坐标均为 x=16、y=13.25，尺寸均为 32 × 32，切换后焦点保持在按钮；无旧路径栏按钮。截图及坐标记录保存在 `.local/ui-fixed-toggle-20260912/`。本次只调整本地界面，没有修改正文或评论数据。
