# v0.0.1 · 首个预览版

> 本页记录 v0.0.1 标签时的功能。当前源码已改为先预览、再确认同步，使用步骤见[项目与同步](../projects-and-sync.md)。

本地飞书文档提供本地编辑、文章目录、源码模式和评论。正文保存在 DocxXML，评论及同步记录保存在相邻 `.review.json`；AI 可以直接读取这两份文件继续改稿。需要发布时，再关联飞书，直接拉取或推送；差异预览可按需打开。

发布页：[To-Re/feishu-doc-local v0.0.1](https://github.com/To-Re/feishu-doc-local/releases/tag/v0.0.1)。这是预览版本，不承诺飞书全部样式无损往返。

## 下载与安装

| 文件 | 用途与安装 |
| --- | --- |
| `feishu-doc-local-browser-v0.0.1.zip` | 静态浏览器版。将解压目录托管到 HTTPS 静态站点，用桌面 Chrome 打开并授权文档目录；不需要 Node 或 CLI。不要直接双击 HTML 使用 `file://`。 |
| `feishu-doc-local-server-v0.0.1.zip` | 预构建的本地服务版。安装 Node.js 22.13+，进入解压目录运行 `npm start`，打开 `http://127.0.0.1:4318/`。无需安装项目依赖；需要飞书同步时另装、配置官方 CLI。 |
| `feishu-doc-local-obsidian-v0.0.1.zip` | Obsidian 基础插件。将其中的 `feishu-doc-local/` 放入库的 `.obsidian/plugins/`，在第三方插件设置启用。无需另装 Node。 |
| `feishu-doc-local-obsidian-sync-v0.0.1.zip` | 可选同步扩展。将其中的 `feishu-doc-local-sync/` 放入同一插件目录并启用；要求基础插件和自行安装、登录的官方 CLI。无需启动网页服务；npm 版 CLI 自身仍需要 Node。 |

本地服务与 Obsidian 同步扩展提供直接「拉取」「推送」及「关联设置」入口，差异预览可以按需打开，两端都有修改时仍需核对确认。推送或新建成功后自动更新本地，旧稿存档；这次交互调整已通过自动化回归，不能据此代替真实云端发布验收。

四种形态共用编辑器与文件协议。浏览器版和基础插件只操作本地文件；同步功能仅在本地服务或可选同步扩展中提供。IDEA / GoLand 不包含在本次发布中。

下载文件可用同页的 `SHA256SUMS` 核验：将四个 ZIP 和该文件放在同一目录，在 macOS 运行 `shasum -a 256 -c SHA256SUMS`。源码下载为 GitHub 从版本标签生成的归档，与四个运行包不同。

## 发布包复现

开发者使用 Node.js 22.13+，在公开源码根目录执行：

```sh
npm ci
npm ci --prefix obsidian-plugin
npm ci --prefix obsidian-sync-plugin
npm run build
npm run build:browser
npm run build --prefix obsidian-plugin
npm run build --prefix obsidian-sync-plugin
npm run licenses:check
npm run release:package -- --output ../feishu-doc-local-v0.0.1-packages
```

打包脚本只读取指定构建目录、公开样稿与许可证，不复制开发历史、`node_modules`、用户配置或运行数据。输出目录必须不存在，避免覆盖已有发布包。ZIP 条目排序、时间与权限固定；同一 Node/zlib 版本下，相同构建输入会生成相同字节和摘要。公开源码使用 `scripts/prepare-public-source.mjs` 的白名单独立导出并审计。
