# v0.0.2 · Obsidian 使用与同步改进

本版重点改进 Obsidian 的文件打开、评论定位和同步流程，网页端继续共用编辑器与文件格式。

## 更新内容

- 在 Obsidian 文件列表点击 XML 时自动判断内容：符合本地 DocxXML 子集的文档进入编辑器，普通 XML 显示只读原文，不创建评论或同步数据。格式识别不证明文件来源；已有其他 XML 插件的关联会保留。
- 改进评论点击定位、选文范围与引用展示；显示已解决评论时也显示对应原文标记，隐藏时清除标记。
- 正文同步统一为先预览差异，再确认拉取或推送；方向与按钮文案一致，确认操作放在易见位置。增加恢复上一份本地快照的入口，恢复前先预览并存档当前版本。
- 修复 Obsidian 同步预览与恢复流程，统一目录、文件面板的收起入口，改善评论作者与处理状态的排版。
- README 补充浏览器、Obsidian 表格与同步预览截图，并说明 DocxXML、本地渲染器和官方 CLI 的分工。

## 下载与升级

| 发布包 | 用途 |
| --- | --- |
| `feishu-doc-local-obsidian-v0.0.2.zip` | Obsidian 基础插件：本地阅读、编辑、评论和保存，无需 Node、CLI 或飞书账号。 |
| `feishu-doc-local-obsidian-sync-v0.0.2.zip` | 可选飞书同步扩展：需要基础插件和已配置、登录的官方 Lark CLI。使用 CLI 独立可执行文件时无需额外安装 Node；通过 npm 安装 CLI 时需要系统 Node。 |
| `feishu-doc-local-browser-v0.0.2.zip` | 静态浏览器版：托管到 HTTPS 后使用桌面 Chrome 打开，授权本地目录即可使用，不提供飞书同步。 |
| `feishu-doc-local-server-v0.0.2.zip` | 预构建本地服务版：安装 Node.js 22.13+ 后运行 `npm start`；无需重新构建或安装项目依赖，同步另需官方 CLI。 |

升级 Obsidian 插件前保存文档并关闭相关标签页，停用插件后替换安装文件，再重新启用。保留原有 `data.json`，其中可能有设置与未保存草稿；正文、旁置 `.review.json` 和资源文件保持原位。安装两个插件时，建议同时升级到本版。下载文件可用 `SHA256SUMS` 核对。

## 已知边界

这是早期版本，不承诺飞书所有组件无损往返。首次同步建议使用副本，并核对预览和结果；旧稿快照用于本地恢复。

自动化测试覆盖编辑器、文件保存、插件宿主和模拟 CLI；它们不代表真实飞书全部样式与云端往返通过。本版自动 XML 路由的模拟宿主测试通过，真实 Obsidian 点击验收仍因界面连接超时未完成。插件暂不支持独立弹出窗口和移动端。

本次 macOS 发布检查通过：共享代码 808 项、Obsidian 基础插件 87 项、同步扩展 147 项测试，三个包的类型检查、四种分发构建及许可证分发检查。需要监听本地回环端口的 77 项测试在解除沙箱监听限制后通过。

完整使用说明见 [README](../../README.md)、[Obsidian 基础插件](../../obsidian-plugin/README.md)和[项目与同步](../projects-and-sync.md)。
